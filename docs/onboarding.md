# 开店上手 SOP（onboarding）

> 写给三四线个体店老板 / 店员的「开店说明书」。**零技术背景**也能照着把店跑起来。
> 每一步都配「**你将看到什么**」，照着对就知道做没做对。
> 技术同学想先把环境跑起来，看 → [本地开发](runbooks/local-dev.md) / [生产部署](runbooks/deploy.md)。

掌柜军师是你手机里的「AI 营销军师」：每天帮你挑**今天最该做的 3 件事**（发券、群发、拼团……），点一下「一键执行」它就替你做；还能帮你管商品、开单记账、给老客发会员卡、记储值。

先记住三个东西分别在哪儿用：

| 名字 | 是什么 | 谁用 / 在哪开 |
|---|---|---|
| **商家小程序**（merchant-mp） | 你开店、看生意的主战场 | 老板 + 店员，微信里搜/扫小程序码 |
| **顾客小程序**（consumer-mp） | 顾客领券、亮会员码、查余额的地方 | 你的顾客，微信里 |
| **电脑后台**（admin-web，经营看板） | 大屏看数据 + 批量录商品 + 手动充值 | 老板 / 店员，电脑浏览器 |

> 本手册所有操作都**不需要顾客在线付款**（见第 4 节「本版边界」）。

---

## 0. 一分钟看懂整套流程

```
你录商品/会员 → AI 每天给你 3 件事 → 你点「一键执行」
   → 顾客扫码领券、入会 → 到店亮会员码 → 你核销（记积分/扣储值）
   → 储值：顾客线下给钱，你手动给他加余额 → 晚上看「当日小结」营业额
```

下面分四步带你走一遍：**开店准备 → 核心闭环演练 → 想要现成数据看 → 本版边界 / 常见卡点**。

---

## 1. 开店准备

### 1.1 登录商家小程序

1. 微信打开**商家小程序**，第一次会自动跳到登录页。
2. 填三样：**租户ID**（MVP 单租户期默认 `1`，先照填）、**手机号**（11 位）、**密码** → 点登录。
3. 你将看到：登录成功自动进入「**今日**」首页。
   - 若提示「登录失败」：手机号/密码不对（后端不区分是账号不存在还是密码错，统一这么提示）。
   - 若提示「请填写完整登录信息 / 请输入 11 位手机号 / 租户ID不正确」：是表单没填对，改完再点。

> 账号从哪来：老板/店员的「手机号 + 密码」由平台运营在后台开通后发给你（见 FAQ Q7）。本手册不展开后台开通。

### 1.2 录入第一个商品

> 商品进系统，开单、库存、AI 推荐才有得用。

**手机上（适合一两个商品）：**
1. 进商家小程序「**开单**」页。
2. 右上角「**扫码**」对准商品条码 → 系统查条码（`GET /v1/boss/catalog/products/barcode/:barcode`）。
   - 命中 → 直接进购物车（说明这个商品已录过）。
   - 没查到 → 说明还没录，去电脑后台批量录（见下），或先在后台单个新增。

**电脑上（适合一次录一批，推荐）：**
1. 浏览器打开电脑后台 → 「**商品**」页（`catalog/products`）。
2. 点「**新增商品**」逐个录；商品多用「**批量导入**」一次贴一批（后端接口 `POST /v1/boss/catalog/products/import`，一次最多 500 条，JSON 数组）。
3. 每条商品字段：`name`(名称，必填) / `price_cents`(售价) / `cost_cents`(成本) / `barcode`(条码) / `category`(分类) / `unit`(单位)。
   - ⚠️ **金额单位是「分」**：卖 7.99 元就填 `799`，成本 4 元填 `400`。
4. 你将看到：批量导入返回「**成功 N 条 / 失败 M 条**」，失败的会标明第几行、什么原因，改了再导（坏行不会搅黄整批）。

### 1.3 录入会员

> 会员**主要靠顾客扫码自动入会**（见 2.3），一般不用你手工录。

- 顾客第一次用顾客小程序（领券/看会员码）时，系统会**自动给他开户**（含 0 余额的储值账户），你不用管。
- 你将看到：会员陆续出现在电脑后台「**会员**」页（`membership/members`）和商家小程序「我的」页的「会员总数」里。
- 若平台运营帮你在后台「会员」页手工加过会员，那是试运营动作，日常不需要。

## 2. 核心闭环演练（把店跑起来）

> 建议照顺序走一遍，每步都对照「你将看到什么」。

### 2.1 看「AI 今日 3 件事」

1. 商家小程序「**今日**」首页（`pages/today`），下拉可刷新。
2. 系统将今天的经营建议整理成最多 **3 张卡片**（如：给 7 天没来的老客发张券、给临期商品搞个拼团、发个储值促销），每张卡片写清「要做什么、为什么」。
3. 你将看到：
   - 正常 → 3 张建议卡片。
   - 顶部一条**黄色提示**（如「数据不足，使用冷启动剧本」「AI 未配置，使用规则建议」）→ 正常！说明 AI 暂时降级成规则建议，建议照样能用（缓存命中的建议不提示）。
   - 一张卡片都没有 → 空状态，明天再来看。

### 2.2 一键执行

1. 点某张卡片进**详情页**（`pages/task-detail`）。
2. 点「**一键执行**」（后端 `POST /v1/boss/aiengine/strategies/:id/items/:itemID/execute`）。
3. 你将看到执行结果，常见两种：
   - **已执行**（绿色）→ 军师已替你把这件事办了（比如券已创建、触达任务已下发）。
   - **被拦截 / 失败**（带原因）→ 也别慌，读原因即可，最常见的是**毛利护栏**：军师发现这个优惠力度会亏钱，主动拦下了（错误码 60001）。这是保护你，不是坏了。
4. 想在大屏看更多策略与执行状态，去电脑后台「**AI 策略**」页（`aiengine/strategies`）。

### 2.3 顾客扫码领券、入会

1. 顾客微信打开**顾客小程序**，进入「**领券入会**」页（`pages/join`）。
2. 顾客点「授权手机号」→ 系统自动：登录 → 开户 → 发一张「**新人见面礼 满30减10**」（领了 7 天内有效）。
   - 若顾客店里已有别的新人券（标题含「新人/新客/见面礼/新会员」），就发那张；没有才自动建上面这张默认券。
   - **重复领不会重复发**：已领过的顾客再点，会拿到同一张券，不会刷一叠。
3. 你将看到：顾客领到券，出现在他的「**券包**」页（`pages/coupons`）；同时他成了会员，出现在你的后台「会员」列表里。

### 2.4 亮会员码 → 核销 / 积分

1. 顾客到店，打开顾客小程序「**会员码**」页（`pages/member-code`），亮出一个**动态码**（**60 秒有效**，过期重新生成即可）。
2. 店员用这个码**核销**（后端 `POST /v1/boss/membership/redeem`，入参 `code`，可选 `consume_cents` 扣储值 / `earn_points` 记积分）。
3. 你将看到：
   - 核销成功 → 自动完成「扣储值 / 记积分」。
   - 提示「**会员码无效或已过期**」（40003）→ 码过了 60 秒，让顾客刷新重亮。
   - 提示「**余额不足**」→ 储值不够扣，先充值（见 2.5）。
   - 提示「**会员已被冻结**」（42302）→ 该会员已被后台冻结。
4. 顾客随时能在「**积分**」页（`pages/points`）查自己的积分明细。

> 顺带：顾客用掉的「满30减10」这类券，券核销走 `POST /v1/boss/marketing/coupons/redeem`（同样被毛利护栏守着，亏钱的发不出、用不了）。

### 2.5 储值（店员手动充值）

> 本版**不做在线支付**：顾客**线下把钱给你**（现金 / 扫你个人收款码），你再**手动**给他加余额。赠送规则照常生效。

1. 顾客线下把钱给你（比如 200 元现金）。
2. 你打开电脑后台「**会员**」页 → 找到该会员 → 点「**储值充值**」，输入他实付金额（单位**分**，200 元填 `20000`）。
   - 后端 `POST /v1/boss/membership/members/:id/recharge`。
3. 系统按档位**自动加赠送**：

   | 实付 | 送 | 到账余额 |
   |---|---|---|
   | 充 200 | 送 20 | 220 |
   | 充 500 | 送 80 | 580 |
   | 充 1000 | 送 200 | 1200 |

   （不到 200 不送；取满足条件里最高的一档。）
4. 你将看到：「充值成功：本次 200 元（赠送 20 元），余额 X 元」。
   - 提示「**超过储值上限**」（60003）→ 这张卡到了你设的单卡余额上限，防囤卡风险。
5. 顾客在自己「**余额**」页（`pages/balance`）能实时看到本金 + 赠送余额。

> 资金安全说明：钱是顾客线下直接给你的，**不经过平台、不过系统**，天然合规；系统里这笔充值只是「记账」，不影响你已收到的现金。

### 2.6 开单（顺带）

1. 商家小程序「**开单**」页（`pages/billing`）：扫码 / 搜索把商品加进购物车 → 点「**开单**」→ 弹窗确认「**收款**」。
2. 你将看到：开单回执，库存自动扣减；这单计入当日流水。
   - 顾客是会员要挂这单，下单时带上他的 `member_id`（积分自动累计）。
3. 电脑后台「**商品**」「**库存**」页可改价、看批次/临期。

### 2.7 当日小结（看营业额）

1. 商家小程序「**我的**」页（`pages/me`）直接看「今日营业额 / 订单数 / 客单价 / 会员总数」。
2. 想看曲线图，上电脑后台「**经营看板**」（`dashboard`）：今日营业额、订单数、实收、客单价 4 张卡 + 热销商品 Top5 条形图 + 近 7 日营业额趋势线。
3. 你将看到：今天的真实经营数字。

## 4. 本版边界（MVP 无支付版）⭐

这一版为了**先跑通、不被资质卡住**，做了三个「暂缓」，请你知悉：

1. **不做在线支付**。微信支付服务商进件的资质门槛重、周期长，会卡住开店验证，所以 MVP 先砍掉。
   - 你**收不到**顾客在小程序里的在线付款；储值 = 顾客**线下付款** + 你**手动加余额**（见 2.5）。
   - 支付相关接口本版**直接 404**（`POST /v1/boss/payment/*`、`POST /v1/wxshop/payment/notify` 没注册）。
2. **储值 = 店员手动记账**。资金线下直接给你、不过平台，合规更稳；赠送、消费扣减、余额查询、会员码核销这些功能一个不少。
3. **订阅全免费**。MVP 期间所有功能免费用（免费版 L1），付费墙不启用（`/v1/boss/subscription*` 本版 404）。

> **V1 恢复**：等资质到位，在线收款（资金直清你的特约商户，平台不碰钱）、付费订阅会一并打开——相关代码已写好并保留，只是配置层暂时关着，开关一开即恢复，不用重做。

## 5. 常见卡点 FAQ

**Q1：新建的商品 ID 怎么不是 1？**
A：正常。dev / 内存模式下商品 ID 从 **1001** 起（连了数据库则按数据库自增）。开单、导入时按页面显示的 ID 用即可，别假设从 1 开始。

**Q2：顾客小程序一直转圈、登录不了？**
A：顾客端登录走微信 `wx.login` → `POST /v1/wxshop/auth/login`，**需要后端配好真实小程序 `appid/secret`**（`ZG_WX_APP_ID` / `ZG_WX_SECRET`）才能换到微信身份。dev 没配微信密钥时顾客端登录走不通——这是环境配置问题，不是功能没做。让技术同学核对密钥（见 [real-keys](runbooks/real-keys.md)）。

**Q3：顾客的券/会员码/余额是空的？**
A：三样都需要顾客**先用顾客小程序登录过**（登录即自动开户）。没登录过，自然没券、没码、余额为 0。引导顾客扫一次码入会即可（见 2.3）。

**Q4：金额为什么对不上，差 100 倍？**
A：系统所有金额单位是「**分**」。填售价、充值、查接口返回的数字时记得换算：`799` 分 = 7.99 元。后台表单、接口字段（`*_cents`）都是分。

**Q5：点「一键执行」却被拦了？**
A：多半是**毛利护栏**（60001）在保护你——这个优惠力度会亏钱，军师主动拦下；也可能是触达太频繁被「频次熔断」拦了。读卡片上的原因即可，不是系统坏了。

**Q6：会员码核销报「无效或已过期」（40003）？**
A：动态会员码只有 **60 秒**有效期。让顾客在「会员码」页刷新一下重新亮码，再核销。

**Q7：商家小程序登录要什么账号？租户ID 填什么？**
A：登录要「手机号 + 密码」，这条账号由**平台运营**在后台开通后发你（涉及权限，本手册不教开通）。MVP 单租户期**租户ID 默认填 `1`**。忘了密码找运营重置。

**Q8：哪些事这版暂时做不了？**
A：顾客小程序里在线充值/在线付款（见第 4 节）、C 端埋点批量上报（`POST /v1/track/batch` 后端未提供）。相关代码保留、V1 开启，前端对这些都做了优雅降级，不会卡死。
